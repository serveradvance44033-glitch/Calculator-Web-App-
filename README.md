# Complete Calculator Website

A complete responsive calculator that runs directly in any modern browser.

Features:
- Addition, subtraction, multiplication, division
- Decimal calculations
- Percentage
- Delete and clear
- Keyboard support
- Mobile responsive design
- Light/dark theme toggle
- No backend or API required
- Works offline

## Run
Open `index.html` in Chrome, Edge, Firefox, or Safari.

## GitHub Pages
Upload `index.html` to the root of a GitHub repository, then:
Settings -> Pages -> Deploy from a branch -> main -> /(root) -> Save
